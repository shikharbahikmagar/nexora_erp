# Nexora ERP

Nexora ERP is a modern **Enterprise Resource Planning system** built with Laravel, designed to manage company operations and HR processes in one centralized platform.

## Features

* 🏢 Company & Branch Management
* 👥 Employee Management
* 🏛️ Department Management
* 📄 Staff Documents
* 🔐 Role & Permission Management
* 🔑 Authentication & Authorization
* 📡 RESTful API
* 🖥️ Filament Admin Panel
* 📚 API Documentation

## Tech Stack

* **Laravel 13**
* **PHP 8.4**
* **PostgreSQL**
* **Redis**
* **Filament**
* **Laravel Sanctum**
* **Spatie Permission**
* **Docker**

## Project Status

🚧 **Under active development**

More modules including attendance, leave, payroll, contracts, and performance management are planned.
